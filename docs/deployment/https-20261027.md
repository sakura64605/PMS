## 切换和验证

先备份原配置，再只开启 HTTPS；外网访问通过后才开启域名 HTTP 跳转。每阶段执行 `nginx -t`，失败恢复上一份配置。Java 应用没有重启，没有更新业务 JAR、数据库或前端产物。

通过的检查：

1. 服务器本机及外部客户端验证证书链、域名和有效期；没有使用跳过证书校验选项。
2. HTTPS 首页、三个入口静态资源可访问。
3. 宠物列表业务响应成功，管理员登录成功，AI 会话查询成功。
4. 带身份的 SockJS info 正常；通知 WSS 和 AI WSS 完成 101 握手及 ping/pong，不发送聊天内容，不触发付费模型。
5. 域名 HTTP 跳转到 HTTPS，保留查询参数。

最初检查遇到重载后新监听尚未就绪，增加就绪等待；另一次匿名访问 SockJS info 返回预期 401，改为带身份验证。两次未通过时均恢复原 HTTP 配置，最终成功批次为上述发布目录。

此验证不代表已经接入地图或实际采集用户定位，也不代表全部页面经过人工视觉检查。换域名后浏览器存储按源隔离，用户可能需要重新登录。

## 回滚

如需撤销此次入口切换，可恢复备份配置：

```bash
sudo cp /opt/pms/releases/https-20261027-083949/nginx-before.conf /etc/nginx/conf.d/pms.conf
sudo nginx -t
# 仅语法检查成功后执行：
sudo systemctl reload nginx
```

这会恢复原 HTTP 入口并停用本次 HTTPS 路由；不需要修改应用或删除数据库数据。先保留已安装证书，后续续期或回滚排查均不要把私钥内容写入日志或仓库。
