# 前端切页性能优化

代码提交：`dba1bb4`。2026-10-24 12:32:11（北京时间）发布前端；12:30:10 平滑重载站点 Nginx 配置。

## 实施内容

- 保留原页面直到目标页面准备好的直接切换逻辑，不重新引入中间加载页或跨页业务数据缓存。
- 登录后在空闲时预加载聊天组件；管理员同时预加载后台组件。导航移入或键盘聚焦也提前加载对应模块。共享进行中的代码下载，失败的预加载可重试；节省流量或 2G 网络不进行主动空闲预加载。
- 带 conversation 参数进入私信时，并行请求会话列表和消息历史，减少一轮串行等待。服务端会话归属校验保持原样。
- ECharts 改为按需引入折线图、坐标系、图例、提示和 Canvas 渲染器，统计入口移入或聚焦时预加载图表代码。
- Nginx 为 JS/CSS/JSON/SVG 启用 gzip。带内容哈希的 `/assets/` 文件缓存一年并标记 immutable，HTML 使用 no-cache 重新验证，缺失资源返回 404。API 与 SockJS 代理保持原配置，不给业务接口设置静态长期缓存。
