# 迁移后旧代码清理（2026-10-25）

## 清理结果

删除 73 个不再使用的主代码文件：57 个已被替代的旧业务 Bean，5 个配套旧工具/接口/调试入口，3 个没有调用方的仓储占位文件，以及 8 个已废弃且没有使用点的旧限流、旧缓存注解切面和未注册的 XSS 过滤链文件。现行 Redis 限流、缓存组件、鉴权和其他共享基础设施继续保留。

没有删除共享实体、Mapper、DTO、现行接口、控制器或 WebSocket 入口，没有更改请求路径或数据库表结构。PMS-vue、new-pms 等前端目录不在本轮后端清理范围内。

## 测试调整

- 删除 7 个仅服务旧实现或新旧运行时对比的测试类，以及不再使用的整库等价性 seed SQL 和加载辅助方法。
- 用户缓存、活动任务测试改为调用现行 UserProfiles、UserAvatarCommands 和 ScheduledBusinessTasks。
- 评论回复链接回归改为验证新评论服务发出的真实通知事件；新增 4 项评论数据库回归，验证父评论归一化、计数只增加一次、回复锚点、历史类型兼容、空页参数及非法类型不入库。夹具在独立测试事务中回滚，不覆盖固定 ID 数据。
- 删除旧通知实现前，从旧实现固定 23 组消息载荷为 contracts/notification-payloads.json；通知兼容测试改为读取这份固定基线，避免比较新实现自身或继续依赖旧源码。
- 接线测试保留新服务注入和缺少实现时启动失败检查；BusinessOwnershipTest 进一步检查 73 个被移除类在运行类路径中不存在。
