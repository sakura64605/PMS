# 活动模块完整接管

## 当前状态
活动全部业务入口已由 PmsActivityServiceImpl（@Primary）接管，包括发布、编辑、报名、
取消、签到、列表、详情、报名名单、删除、回收站和恢复。
控制器仅依赖原 ActivityService 接口；旧 ActivityServiceImpl、原 DTO 和数据表保留。
本批未修改请求路径。

## 查询与装配
ActivityQueries 统一查询权限及分页，ActivityDtoAssembler 批量装配作者和报名信息。
公开查询只能看到已审核且未删除、未下架的活动；指定其他作者 ID 不能绕过审核过滤。
我的活动使用登录用户身份，可查询自己的待审、拒绝与下架内容，并支持审核状态筛选。
回收站仅展示登录用户自己的记录，忽略传入的其他作者 ID。
详情允许组织者和管理员预览待审、拒绝或下架内容；已删除详情仍不可访问。
报名名单含姓名电话，只允许组织者读取，不向其他用户或管理员开放。
作者已注销时使用占位信息，避免空指针。
分页使用公共 PageQuery，页大小最高 100，翻过末页仍保留真实总数，排序追加 ID 保证稳定。
报名和点赞状态按当前用户每次查询，不放入共享响应缓存；取消记录不再视为有效报名。
详情保留整数 isLike，同时新增布尔 isLiked，兼容 React 的点赞状态读取。
登录的非作者访问公开详情时原子增加浏览数，不整行写回。

## 删除与恢复
ActivityLifecycleCommands 先锁活动行，再检查身份和状态，只更新删除标记及更新时间。
活动已结束，或实际结束时间已到，都不能删除或恢复。
删除只允许组织者；恢复沿用组织者或管理员权限。
删除取消未执行的三类活动任务，恢复重建时间任务，并为待审内容补齐审核记录。
缓存和搜索同步在提交后触发；事务回滚不发布搜索同步事件。
旧提醒任务增加审核、删除标记和当前时间窗口检查；
旧统计任务通过数据库条件更新，拒绝处理已删除、未审核、未结束的活动。
