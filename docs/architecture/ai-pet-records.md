# 宠物档案跨会话记录（2026-11-05）

宠物档案是宠物事实的唯一业务来源，不另建宠物长期记忆库。新增 ai_pet_record，按 user_id + pet_id 隔离：habit（习惯）、note（注意事项）、event（历史事件）。事件区分 occurred_on（发生日期，可未知）和 created_at（保存时间），event_state 为 unknown/ongoing/resolved；状态均为用户陈述，不是诊断。

## 使用

管理宠物档案 → 档案记录，可新增、纠正、补充后续、删除；每页50条。用户消息下方可点击“保存到宠物档案”，整理并确认内容后保存。第一版采用用户主动选择消息，不自动调用模型提炼或写入。助手消息不允许直接作为来源。后端校验来源消息属于当前用户、当前宠物会话，唯一来源索引避免重复；删除清空记录内容并保留来源标记，禁止同一消息重新保存，仍允许用户手动重新确认新增。原聊天历史保留。

每轮读取当前宠物档案，注入最新6条习惯/注意事项，以及按问题双字关键词检索的最多6条历史事件；提示资料仅为数据，日期未知不能推断为今天、历史状态需核实。此为轻量检索，不保证覆盖全部病史。新会话可以使用已确认记录，无需读取其他会话全文。

宠物会话继续不读取或抽取用户级长期记忆；通用会话的抽取提示收窄为用户自身偏好，明确排除宠物资料。旧用户记忆未自动迁移或删除，提示其宠物内容不可作为事实。历史消息/摘要可能仍包含旧陈述，提示词要求以当前档案为准；不宣称从原聊天中删除了信息。
