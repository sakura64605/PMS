# 用户与账号管理重构

## 本批接管
PmsUserServiceImpl 接管原 UserService 的全部7个方法：登录、注册、当前用户信息、
资料更新、密码修改、用户搜索和公开个人资料。
PmsAvatarServiceImpl 接管上传、历史列表与历史切换。
PmsAdminServiceImpl 不再把账号操作转交旧 AdminServiceImpl，而由 UserAdministration /
UserAdminItem 处理列表、批量启用、批量禁用和批量重置密码；审核仍走既有新审核服务。
旧 UserServiceImpl、AvatarServiceImpl、AdminServiceImpl 保留；原表和HTTP路径保持不变。
原 DTO 保留，资料更新 DTO 仅补充 Jackson builder 反序列化配置。

## 结构与复用
- UserAuthentication：注册与验密，使用统一 PasswordEncoder Bean。
- UserProfiles：资料、密码修改、搜索和公开资料查询。
- UserAssembler：集中装配安全返回模型与隐私字段。
- UserSessions：令牌签发、数据库状态/角色校验、退出与兼容会话失效。
- UserAvatarCommands：头像数据库事务、归属校验、历史整理。
- UserAdministration / UserAdminItem：批量协调与每个账号独立事务。
- UserRestrictions：两种历史报名限制时间统一取较晚值。
- UserCache：提交后失效 user 缓存。

## 规则修复
登录必须先验密，再更新活跃时间，且更新同时检查密码和正常状态，避免旧用户快照整行覆盖。
注册以数据库唯一键作为最后约束，并将并发冲突转换为业务错误；布隆过滤器仅在提交后更新，
不作为账号是否存在的权威判断。
当前用户信息按登录 ID 查询，资料更新返回完整模型。password 字段不删除，但返回值为 null，
不再把密码哈希发给客户端。日志不再记录改密请求体。
资料和密码写入均校验当前用户归属、锁定用户行，只更新明确允许的字段。
邮箱显式空字符串转换为数据库 NULL；重复邮箱回滚本次资料更新。
公开资料逐请求检查 phone/email/tags 隐私及当前关注关系，不共用个人化响应缓存。
搜索仅返回可搜索且正常的用户，并限制10条。
管理员分页复用 PageQuery、最高100条，末页之外仍保留真实总数。
批量操作保持部分成功的返回结构，逐账号独立提交；重复、无效、自禁用等项目返回失败原因，
数据库内部错误不直接返回客户端。重置密码仍沿用既有默认密码123456。
管理员手动启用/禁用会在用户锁内撤掉旧的限时封禁任务；已处于禁用状态但仍有旧限时任务时，
手动禁用仍能覆盖为人工禁用，避免旧任务将其重新启用。

## 会话
新 JWT 增加与密码版本绑定的签名声明，修改或重置密码后，旧版本令牌无法继续通过认证。
修复 JWT 创建时 setClaims 覆盖随机 jti 的问题，保证同一秒内的不同登录仍有独立令牌。
退出登录仅将当前令牌摘要加入 Redis 失效集合，TTL 为令牌剩余有效期，不影响其他会话。
HTTP 权限使用数据库当前状态和角色，禁用或角色变化后不会继续使用旧JWT权限。
兼容旧格式 JWT：密码修改提交后写入有期限的 Redis 失效标记；该兼容路径依赖 Redis 正常工作。
新格式令牌的密码版本校验直接使用数据库密码，无需依赖这一标记。
HTTP、通知 WebSocket 握手及推送、AI WebSocket 握手及后续消息均接入新的会话检查。
AI WebSocket 显式将认证后的用户 ID 交给引擎。
已存在的连接在下一次推送/消息时检查，并非新增了主动广播断开所有连接的机制。

## 头像与副作用
文件上传使用原 OSS 工具，放在数据库事务之前；账号写入、历史记录在新事务中完成。
历史最多保留11条（与旧实现的实际常量一致），只删除历史记录，不删除可能被帖子引用的OSS文件。
上传成功而后续数据库写入失败时仍可能留下未引用文件，本批未实现媒体回收任务。
资料、头像、密码、管理员操作与限制到期恢复都在提交后失效用户缓存。
XXL 到期任务和管理员操作采用一致的“用户行→任务”锁顺序；
报名限制的两个历史时间字段按较晚值判断，避免提前解除较长限制。
本批不重建搜索索引中的历史作者冗余字段，不调整前端页面布局。
