# 首页按 React 原型补齐（2026-10-27）

依据用户提供的 `petcircle-宠友社/src/components/DashboardView.tsx` 逐区重做，入口仍为 `/dashboard`。首页组件独立为 `PMS-react/src/dashboard.tsx`，旧 `content.tsx` 保留 Home 导出以兼容路由引用。

| 原型区域 | 实现与真实数据 |
|---|---|
| 渐变欢迎横幅 | 莫兰迪渐变、爪印、北京时间问候、昵称、真实公开记录总数；浏览领养、带计数的我的报名和发布选择弹窗 |
| 社区公告与动态 | 置顶、优先级配色、类型、已读标题样式、发布日期、详情箭头；调用真实未读总数。默认每页4条，超出可翻页 |
| 四个快捷入口 | 领养、活动、日记、AI顾问；各有对应图标、底色、说明及正确筛选路由 |
| 寻家宠物卡片 | 三列4:3封面、送养/救助标签、品种、名字、性别年龄、正文摘要、地点、浏览和点赞；查询仅已发布状态 |
| 同城活动 | 两列卡片、状态、日期、说明、报名人数/上限/百分比、进度条、地点、详情与报名入口 |
| 日记精选 | 两列作者头像、昵称、时间、内容与话题，进入具体日记详情；游客保留该区域并提示登录 |

不硬编码天气晴朗、今日新增4只/2场，使用中性欢迎提示及真实公开数量；不宣称社区内容审核等同健康和实名核验。无真实数据的字段不会编造数字。

宠物列表原先没有正文和地点，DTO 新增 `content`（最多200字符）与 `address`，沿用现有列表批量装配，不对首页卡片逐条请求详情，不返回联系方式。原响应字段和路径保持不变，无数据库变更。

各区域独立保留加载、空态和错误重试，单一区域失败不隐藏整页。图片沿用 RouteImage，在页面切换后加载，不阻塞导航。样式局限于 dashboard 命名空间；桌面快捷入口4列、宠物3列、活动与日记2列，小屏按原型折叠。

相关验证：5项首页组件测试覆盖所有区域与真实字段、发布入口与路由、游客权限、局部失败和北京时间问候；宠物列表转换测试验证摘要长度和地点；执行 TypeScript / Vite 构建。本批仅本地修改与验证，未部署。
