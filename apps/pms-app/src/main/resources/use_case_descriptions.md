# PMS 宠物管理系统 — 用例描述

## 1. 用户管理

| 编号 | 用例名 | 参与者 | 描述 |
|------|--------|--------|------|
| UC1 | 用户注册 | 用户 | 提供手机号、用户名、密码注册新账号，注册成功即自动登录 |
| UC2 | 用户登录 | 用户 | 使用账号密码登录，获取JWT令牌 |
| UC3 | 退出登录 | 用户 | 调用退出接口，前端清除本地登录状态 |
| UC4 | 查看个人信息 | 用户 | 查看自己的头像、昵称、标签、隐私设置等完整资料 |
| UC5 | 编辑个人信息 | 用户 | 修改昵称、个性签名、性别、邮箱、标签、隐私可见性 |
| UC6 | 查看他人主页 | 用户 | 查看其他用户的公开资料信息 |
| UC7 | 搜索用户 | 用户 | 按关键词搜索平台上的其他用户 |
| UC8 | 修改密码 | 用户 | 验证旧密码后设置新密码 |
| UC9 | 上传头像 | 用户 | 上传新头像图片，原头像自动进入历史记录 |
| UC10 | 切换历史头像 | 用户 | 从历史头像记录中选择并切换到指定头像 |

## 2. 宠物帖子

| 编号 | 用例名 | 参与者 | 描述 |
|------|--------|--------|------|
| UC11 | 发布宠物帖子 | 用户 | 发布领养或救助类型宠物信息，含标题、内容、图片、联系方式 |
| UC12 | 查看宠物帖子 | 用户/游客 | 浏览宠物帖子列表和详情，支持筛选和排序 |
| UC13 | 编辑宠物帖子 | 用户 | 修改自己已发布的宠物帖子信息 |
| UC14 | 删除宠物帖子 | 用户 | 将宠物帖子移入回收站（软删除） |
| UC15 | 彻底删除宠物帖子 | 用户 | 从回收站永久删除宠物帖子 |
| UC16 | 恢复宠物帖子 | 用户 | 从回收站恢复已删除的宠物帖子 |
| UC17 | 下线宠物帖子 | 用户 | 将已发布的宠物帖子下线，不再对外展示 |
| UC18 | 标记已完成 | 用户 | 将宠物帖子标记为已领养/已救助状态 |
| UC19 | 收藏/取消收藏 | 用户 | 收藏感兴趣的宠物帖子或取消收藏 |
| UC20 | 查看收藏列表 | 用户 | 查看自己收藏的所有宠物帖子 |

## 3. 互动

| 编号 | 用例名 | 参与者 | 描述 |
|------|--------|--------|------|
| UC21 | 点赞/取消点赞 | 用户 | 对帖子、动态、评论等内容点赞或取消点赞（统一点赞接口） |
| UC22 | 发表评论 | 用户 | 对帖子或动态发表评论，支持对已有评论进行回复 |
| UC23 | 查看评论列表 | 用户/游客 | 查看内容的评论列表 |
| UC24 | 删除评论 | 用户 | 删除自己发表的评论 |
| UC25 | 关注/取消关注用户 | 用户 | 关注其他用户以接收其动态，或取消关注 |
| UC26 | 查看关注列表 | 用户 | 查看自己关注的用户列表 |
| UC27 | 查看粉丝列表 | 用户 | 查看关注自己的用户列表 |

## 4. 活动管理

| 编号 | 用例名 | 参与者 | 描述 |
|------|--------|--------|------|
| UC28 | 发布活动 | 用户 | 创建线下活动，填写标题、内容、地点、时间及人数上限 |
| UC29 | 查看活动列表 | 用户/游客 | 浏览活动列表和详情，支持筛选 |
| UC30 | 编辑活动 | 用户 | 修改自己已发布的活动信息 |
| UC31 | 删除活动 | 用户 | 将活动移入回收站（软删除） |
| UC32 | 恢复活动 | 用户 | 从回收站恢复已删除的活动 |
| UC33 | 报名活动 | 用户 | 报名参加活动，填写姓名、电话和备注信息 |
| UC34 | 取消报名 | 用户 | 取消已报名的活动 |
| UC35 | 活动签到 | 用户 | 在活动现场签到，确认参与 |
| UC36 | 查看我的活动 | 用户 | 查看自己发布和报名的所有活动 |
| UC37 | 查看报名列表 | 用户 | 查看已报名某活动的用户列表 |

## 8. 举报
